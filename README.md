# CDEK News Component - Тестовое задание

Проект представляет собой реализацию универсального компонента новостного блока для внутреннего портала компании CDEK.

На одной странице собраны несколько вариантов использования компонента:
- Новостная лента компании;
- Вариант блока для рубрики "Бизнес";
- Пустое состояние блока.

### Используемый стек
- React 19 + Vite + TypeScript
- SCSS
- Tabler Icons

## Реализованный функционал
### Основные требования
- Загрузка новостей из API
- Отображение skeleton во время загрузки данных
- Обрабатывает состояния загрузки, ошибок и пустого списка
- Поддержка пагинации
- Адаптивная версия для мобильные устройства
### Основные дополнительные требования
- Кэширование ответа API с новостями для конкретной страницы 
- Планое появление карточек с новостями
- Использование TypeScript (типы и интерфейсы)
- Форматирование дат - Апрель 2026, 27 марта в 18:52, Воскресенье, 19 апреля

## Принятые решения
- Основная логика загрузки вынесена в кастомный хук `useNews`, чтобы отделить работу с API от UI-компонентов
- Для повторных переходов по страницам используется кэш `Map`, поэтому уже загруженные данные не запрашиваются повторно
- Форматирование дат централизовано в `dateFormatter`, чтобы не дублировать логику в интерфейсе
- Реализвана вариативность некоторых компонентов таких как Typogrphy и Chip для более удобного переиспользования

### Что можно улучшить
- Реализовать ленивую загрузку изображений для карточек новостей
- Доработать компоненты, чтобы приблизить их внешний вид к макету

## Установка и запуск проекта

```bash
git clone https://github.com/Minory54/CDEK-frontend.git

npm install
npm run dev
```

После запуска проект будет доступен по адресу: `http://localhost:5173`

Проект использует для подключение API
